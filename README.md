# Prosjekt uke 41–42 – Mobilapp med React Native

Prosjektet inneholder flere Expo-apper laget med React Native:

- `./` – værmelding med søk etter sted og værdata fra Open-Meteo
- `./password-generator` – passordgenerator med valg av tegn og minimum antall symboler
- `./tidsmaaler` – tidsmåler for ulike gjøremål
- `./shop-app` – nettbutikk med kategorier, produkter og handlekurv

## Start en app

Gå til mappen for appen du vil kjøre, installer avhengighetene og start Expo:

```bash
cd shop-app
npm install
npx expo start
```

Bytt `shop-app` med `password-generator` eller `tidsmaaler` for å starte en av de
andre appene. Værmeldingsappen startes fra prosjektets rotmappe.
