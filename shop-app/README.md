# Oppgave 8 – Nettbutikk

En selvstendig Expo-app for produktkategorier, produktvisning, antallsvalg og handlekurv.

Start appen fra denne mappen:

```bash
npx expo start
```

Skann QR-koden med Expo Go. Velg en kategori, trykk på et produktbilde for å åpne det stort, legg varer i kurven, juster antall og se totalsummen. Bestillingsknappen viser en bekreftelse og tømmer handlekurven; appen lagrer ingen betaling eller personopplysninger.
